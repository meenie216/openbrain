# Weekly Review (5 minutes, end of week)

Purpose: end-of-week synthesis across everything captured — cluster by
topic, surface unresolved action items, spot patterns across days, and find
gaps in what's being tracked. Gets more valuable every week as the brain
grows. Run in any MCP client connected to the `openbrain` MCP server.

---

**Prompt:**

> Call `stats` and `list_recent` (last 20-30) on my openbrain MCP server to
> review this week's captures. Then:
> 1. Cluster the thoughts by topic — what themes came up more than once?
> 2. List every action item mentioned this week that doesn't show up again
>    in a later capture as done or superseded — those are likely still open.
> 3. Note any connections between this week's captures and things from
>    `stats`' top_topics/top_people that suggest a pattern worth naming.
> 4. Call out gaps: people or projects you'd expect to see mentioned that
>    didn't come up at all this week.
>
> Give me the result as four short sections: Themes, Open Action Items,
> Patterns, Gaps.
